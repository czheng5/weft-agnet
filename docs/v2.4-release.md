# Weft v2.4.0

> 发布日期：2026-11-04  
> 范围：天禧 AI 项目管理/交互概念整合 + 离线工具自动发现

## 交付

### Workboard

- Thread 项目管理字段：
  - priority
  - owner
  - dueAt
  - labels
- SQLite/Postgres + migration 003
- GET /workboard
- progress / overdue / messageCount / lastEventAt
- deterministic priority/due ordering
- Surface 切换为 workboard 视图

### 天禧 AI 概念取舍

采用：

- 统一任务面板
- 跨入口继续任务
- 优先级/截止/责任人
- 本地/离线模式标识
- 任务进度可视化
- Skills/Marketplace 已有签名基础

不照搬：

- 闭源端-边-云调度
- TEE/芯片级安全（Weft 只有进程/沙箱/权限）
- 会议转录
- 跨设备同步协议

### 离线工具发现

- tool-discovery 扫描：
  - PATH
  - WEFT_EDA_BIN
  - OSS_CAD_SUITE
  - VERILATOR_ROOT / YOSYS_ROOT
  - PDK_ROOT / PDK / OPENLANE_ROOT
  - 常见 PDK 根目录
- EDA gate 使用发现结果，不再把“本机没装”写成产品硬限制
- 是否可签核仍取决于环境真实工具/规则 deck

## 验证

- 133 tests pass
- Workboard API/字段测试
- 工具发现测试
- 天禧概念文档

## 限制

- Surface 仍是单文件，未做项目分组/拖拽/提醒
- 跨设备同步仍是共享 ThreadStore 层，未做设备身份协议
- EDA 工具/PERC 是否可用由运行环境决定
- 真实模型 E2E 未使用 env key（安全策略）
