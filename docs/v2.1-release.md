## 设计边界

- 这是“证据 + 结构 + patch”确定性评估，不是真实 LLM 自动评分。
- 不调用网络，不依赖外部工具。
- 用于检验方案是否引用内部文件、定位行、给出可执行 patch，而不是只给泛泛建议。

## 限制

- 没有接 Verilator/Yosys/OpenSTA 真仿真/综合
- 情景规模小，需继续增加模拟/数字/混合信号/功耗/DFT 场景
- 没有真实模型端到端（需要用户 key）
