> 目标：PRD 中 v1.0 IN（M0–M3）功能开发 + 非 OS 验证；OS/Windows/WSL conformance 最后统一做。

> 范围：v1.0 IN；P1 功能（原生 Windows token backend、CUA driver、多租户）不在本 gate。
