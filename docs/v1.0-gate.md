# Weft v1.0 Gate

> 目标：PRD 中 v1.0 IN（M0–M3）功能开发 + 非 OS 验证；OS/Windows/WSL conformance 最后统一做。  
> 结论：**PASS（代码 + 本地/契约验证 + Docker/WSL OS）**  
> 范围：v1.0 IN；P1 功能（原生 Windows token backend、CUA driver、多租户）不在本 gate。

## 1. 证据

- 自动化测试：**77 tests pass**
- v1.0 demo：**PASS**（真实 Postgres/pgvector + PgVectorIndex）
  - goal=true tasks=2 evidence=1
  - actor childPrefix=demo eventBus=1 schedulerFired=1
  - capability=1.0.0 memoryHits=2 outboxPending=0
- Docker Linux OS 边界：6 项 PASS
- WSL 专用 weft-sandbox 非 root：PASS（uid=1001）
- Agent HTTP 集成：cacheReadTokens=128（本地 OpenAI-compatible provider）
- Guardian 50 动作 shadow harness：50 actions / 0 mismatch
- 真实 Postgres：write/get/search/forget/health PASS
- pgvector v0.8.0 + HNSW + cosine：PASS
