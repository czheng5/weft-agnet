# Weft v2.2 Production-Readiness Baseline

> 范围：用户指定的 4 项优先能力  
> 结论：基础实现 + 测试已落地；仍是 baseline，不是完整 K8s/SaaS。

## 1. 远程签名 Marketplace / 发布者验证

- Ed25519 publisher signatures
- PublisherKey / keyId / publisher
- signature covers bundle sha256 + publisher + keyId + expiry
- 拒绝：
  - 未知 key
  - revoked key
  - expired bundle
  - 篡改 manifest / checksum
  - 错误签名
- 远程 index：
  - fetchSignedMarketplaceIndex
  - 只接受 http(s)
  - 每个 bundle 安装前验证
- 安装：
  - installSignedCapabilityBundle

## 2. OAuth/OIDC + 动态 token 撤销

- OIDC JWT 验证：
  - RS256/RS384/RS512
  - EdDSA
  - iss/aud/exp/nbf
  - kid -> JWKS
  - sub/jti required
- claims -> Principal：
  - tenant_id/project_id/workspace_id
  - role
- 动态撤销：
  - FileRevocationStore
  - jti + expiresAt
  - cleanup
  - Gateway POST /auth/revoke（admin）
- Gateway authenticator 注入点：
  - 静态 principals 或 OIDC authenticator

## 3. Multi-worker fair scheduling

- FairWorkerPool
  - 多 tenant round-robin 选择
  - concurrency
  - 同一 thread 不并发领取
  - lease busy defer
  - heartbeat
  - 未选中的 claimed job 通过 releaseOutbox 放回
- RuntimeStore 新增 releaseOutbox
- 测试：
  - 3 tenant 首次只处理 2 个不同 tenant
  - 第二轮补齐第三个
  - 不重复领取

## 4. 存储/计算分离编排

- DeploymentSpec：
  - stateStore: sqlite/postgres
  - artifactStore: local/s3
  - compute: workers/sandbox
  - secrets: env names only
- LocalArtifactStore：content-addressed sha256
- WorkerFleet：多个 stateless worker
- DeploymentOrchestrator：
  - 校验
  - stable digest
  - 注入 createStore/createArtifactStore
- 测试：
  - 配置校验
  - CAS 幂等
  - 2 worker 对外部 state/artifact 处理 job

## 5. 当前限制

- 未接真实 S3 SDK / Kubernetes/Nomad 启动器
- 未做 OAuth authorization-code flow（只验证已签发 JWT）
- 未做 publisher key rotation 自动发现
- 多 worker fairness 是 tenant round-robin，不是全局加权公平
- 未使用真实模型 key 做仓库内 E2E
- 生产级 HA/备份/配额计费仍需部署层完成
