# Weft v1.5.0

> 发布日期：2026-11-04  
> 范围：M4 Consolidation  
> 结论：**v1.5 gate PASS（代码/契约/真实 PG/迁移）**  
> 注意：v1.5 不是 Super-agent；M5 才实现 Agent Gateway/Router/Worker 运行时。

## 交付

- Runtime schema：
  - Thread / WorkerLease / RuntimeEvent / Mandate / CapabilityManifest / Outbox
- RuntimeStore：
  - SQLite adapter
  - Postgres adapter（pg-mem + 真实 PostgreSQL 契约）
- EventLog：
  - append-only
  - thread-local seq
  - idempotencyKey
- WorkerLease：
  - acquire / heartbeat / release / expired
- Outbox：
  - enqueue / claim / complete / fail / retryAt
- Thread ↔ WorkGraph：
  - 一个 thread 一个 graph
  - threadId 持久化；跨 thread 拒绝
- CapabilityRegistry：
  - 统一到 Runtime CapabilityManifest
  - v1 legacy manifest 只读迁移
- v1.0 数据：
  - 只读快照
  - 显式迁移到 RuntimeStore
  - 原文件字节不变
