# Weft v1.0 Demo

> 默认 SQLite；设置 WEFT_PG_URL 时使用真实 PostgreSQL + PgVectorIndex。

## 默认

~~~powershell
node --experimental-strip-types scripts/v1-demo.ts
~~~

## 真实 PG + pgvector

~~~powershell
$env:WEFT_PG_URL = "postgres://postgres:weft@127.0.0.1:55432/weft"
node --experimental-strip-types scripts/v1-demo.ts
~~~

~~~text
Weft v1.0 demo PASS
  goal=true tasks=2 evidence=1
  plan=plan-530 checkpoint=checkpoi
  actor childPrefix=demo eventBus=1 schedulerFired=1
  capability=1.0.0 memoryHits=2 outboxPending=0
~~~

## 覆盖

- Goal evaluator / Plan / Checkpoint
- Actor fork prefix
- Event Bus
- Scheduler wakeup
- Capability install
- MemoryHub graph + outbox + vector retrieval
