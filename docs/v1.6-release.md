# Weft v1.6.0

> 发布日期：2026-11-04  
> 范围：M5 Agent Gateway / Super-agent baseline  
> 结论：**v1.6 gate PASS（Gateway/Worker/Router/SSE/Watchdog/E2E）**  
> 注意：这不是完整多租户 SaaS；M6 才做 Own Shape/协议/生态/Surface。

## 交付

- Agent Gateway HTTP：
  - threads/messages/events
  - Bearer token
  - idempotency
  - SSE stream
- Router：
  - admission
  - Mandate capability/expiry
  - Outbox 入队
- WorkerPool：
  - claim
  - lease
  - heartbeat
  - complete/fail/backoff
- AgentLoop seam：
  - message event → AgentRunner
  - agent.result
  - 重试幂等
- Watchdog：
  - expired lease 告警
- Eval gate
- HTTP Source
- CLI：
  - weft --serve --port 4780
- 测试：
  - 105 unit/integration tests
  - M5 E2E PASS
  - Gateway health/thread/message smoke PASS

## 限制

- 真实模型端到端需要用户 key，未纳入仓库测试
- Source 只支持 HTTP JSON
- 多 Worker 公平调度未做
- 没有 Web/Desktop、Marketplace、RBAC（M6）
- Watchdog 只告警，不自动恢复
